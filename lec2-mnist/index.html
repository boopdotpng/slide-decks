the dataset

mnist: 70,000 handwritten digits

28 × 28 pixels, grayscale

each image has a label: the digit it shows, 0 to 9

60,000 to train on
10,000 held back to test

written by us census bureau employees and high school students; collected by NIST, cleaned up by LeCun et al. in 1998. the "hello world" of neural networks

real images from the training set, one column per label

the dataset

an image is a grid of numbers

the dataset

the whole dataset is four tensors

the library downloads it for you (about 11 MB)

tensorshapeholds
xtrain(60000, 1, 28, 28)training images, bytes 0–255
ytrain(60000,)their labels, 0–9
xtest(10000, 1, 28, 28)test images
ytest(10000,)test labels
1 is the color channel: mnist is grayscale, so one. a color photo would have 3 (red, green, blue)

/ 255: bytes become floats from 0 to 1

− mean: shift so the average pixel is 0 (the mean is about 0.13). small numbers centered on 0 train better

the test set gets the same mean: it has to look like what the model trained on

why a library

you write array math; it becomes gpu code

def loss(x, w, y): return (x @ w - y).square().mean()

the library records it as a graph of the whole computation

and a compiler turns the graph into code for your hardware

nvidia gpuCUDA
amd gpuHIP
apple gpuMetal
any cpuC, built by clang

the same graph, walked backwards, gives every gradient: that's what backward() does

relu is max(0, x). without it, two matmuls in a row are the same as one; with it the model can learn curves, not just straight lines
